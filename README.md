# TransLang translation models

Offline translation models used by the [TransLang](https://usefulhands.github.io/translang-privacy/)
browser extension in browsers without Chrome's built-in translator (Edge, Brave, Opera, Firefox…).

These files are unmodified copies of the **Firefox Translations models** by Mozilla, run by the
[Bergamot](https://github.com/browsermt/bergamot-translator) engine. They are licensed under the
Mozilla Public License 2.0 (see `LICENSE`). Original source: Mozilla's model registry
(`translations-models` collection on firefox.settings.services.mozilla.com).

The extension verifies every file's SHA-256 hash before using it.
